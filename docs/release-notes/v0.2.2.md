**Admiral and the Deck apps take turns on the keyboard.**

## Fixed

- **Applying in DeckMapper while Admiral ran could break your keys.** The keyboard has one file buffer shared by every program. Admiral writing the now-playing card at the same moment DeckMapper applied could take the buffer halfway through, and DeckMapper's key assignments ended up holding a single key's action file. Admiral, DeckMapper, SlotDeck and TrackDeck now share one lock and use the buffer one file at a time.
- **Two programs starting together could share a session.** They now start their sessions one after the other.

## Please update

Update DeckMapper to 1.2.1, SlotDeck to 1.1.2 and TrackDeck to 1.0.5 too: the lock only helps when every program on the keyboard takes it.

## Get it running

1. Download **Admiral.exe** below.
2. Install the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) if you don't have it.
3. Plug the keyboard in with the **USB cable** and close iCUE.
4. Run it and look for the navy badge in the tray.
