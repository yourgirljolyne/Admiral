**The dial works while SignalRGB has the keyboard.**

## What's new

- **The dial in software mode.** SignalRGB puts the keyboard in software mode, and in that mode the keyboard stops running its dial modes as well as your keys. Admiral now plays the dial modes you set up in [DeckMapper](https://github.com/yourgirljolyne/Deckmapper):
  - **Volume:** turn for volume, press to mute.
  - **Scroll** up/down or left/right.
  - **Zoom:** Ctrl + wheel, press to go back to 100 %.
  - **Switch apps:** Alt + Tab while you turn, press to pick.
  - **Change track** and **seek:** press to play or pause.
  - **Custom actions** for turn right, turn left and press.
- **Changing modes.** The keyboard doesn't say which dial mode it's on, so Admiral keeps track: **FN + dial press** goes to the next mode, and the new **Dial** line in the tray menu shows the current one and lets you pick another. Admiral remembers it.

One click is one step, and nothing fires twice: the keyboard sends nothing for the dial in software mode. Lighting brightness mode does nothing while SignalRGB runs, since SignalRGB owns the lights.

## Get it running

1. Download **Admiral.exe** below.
2. Install the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) if you don't have it.
3. Plug the keyboard in with the **USB cable** and close iCUE.
4. Run it and look for the navy badge in the tray.
