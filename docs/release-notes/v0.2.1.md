**The tray menu opens again, and Admiral plays nicer with SignalRGB.**

## Fixed

- **Right-click did nothing.** Admiral's tray updated its menu from background threads, and a menu built on another thread can't be opened from the tray icon. It showed up most while SignalRGB was running. The tray now always does its work on its own thread.

## What's new

- **Works with the SignalRGB plugin's custom keys.** The [Air 99 SignalRGB plugin](https://github.com/yourgirljolyne/signalrgb-vanguard-air-99) can now play your custom keys and the dial itself (its *Custom keys in software mode* setting). While that's on and SignalRGB runs, Admiral greys out only its own keys switch and dial modes, with the reason, so nothing is typed twice. The card, FN + arrow screens, Open DeckMapper / SlotDeck and everything else stay usable.
- **A watchdog in the log.** If the tray ever stops answering for 5 seconds, the log says what it was doing, and errors on the tray's thread are logged instead of vanishing.

## Get it running

1. Download **Admiral.exe** below.
2. Install the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) if you don't have it.
3. Plug the keyboard in with the **USB cable** and close iCUE.
4. Run it and look for the navy badge in the tray.
