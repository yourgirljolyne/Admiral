**One tray app for the VANGUARD AIR 99: the card, your keys and your screens, even while SignalRGB has the keyboard.**

## What it does

- **Now-playing card.** What's playing in Windows on the keyboard screen: cover, title, artist, play/pause. Your own screen comes back after a set idle time. This is TrackDeck's job, moved in, and Admiral picks up TrackDeck's settings on its first run.
- **Custom keys in software mode.** SignalRGB puts the keyboard in software mode for clean live lighting, and the keyboard then stops running your remaps and macros. Admiral plays the ones you made in [DeckMapper](https://github.com/yourgirljolyne/Deckmapper) from the PC.
- **Screen switching in software mode.** Software mode also stops FN + arrows from switching screens, so the screen got stuck on one picture. Admiral steps through your screen list itself: right/down forward, left/up back. It's the same list [SlotDeck](https://github.com/yourgirljolyne/Slotdeck) manages. A custom FN + arrow made in DeckMapper still wins.

In normal mode the keyboard does its own keys and screens, and Admiral only shows the card.

## The tray menu

One status line per part, Open DeckMapper and Open SlotDeck (found next to Admiral, or wherever they run from), an on/off switch for each part, the card's options, Start with Windows, the log, and Exit, which puts your own screen back.

## With the other apps

- **TrackDeck** isn't needed any more. While it's running, Admiral leaves the card to it; TrackDeck 1.0.4 won't start while Admiral runs.
- **DeckMapper 1.2** hands its key service over to Admiral. An older DeckMapper with the service on keeps playing the keys itself, and Admiral steps back so no key is typed twice.
- **Start with Windows** in Admiral offers to stop TrackDeck and DeckMapper from starting with Windows too.

## Get it running

1. Download **Admiral.exe** below.
2. Install the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) if you don't have it.
3. Plug the keyboard in with the **USB cable** and close iCUE.
4. Run it and look for the navy badge in the tray.

## Good to know

- Admiral writes only the card's own files and the active-screen file. It reads your keys and screen list but never changes them, or your profiles and lighting.
- Custom dial actions aren't played in software mode yet. The dial doesn't show up in the keyboard's key reports.
